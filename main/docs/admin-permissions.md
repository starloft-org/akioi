# 管理员权限

后台采用两级管理员：**超级管理员**（superadmin）与**管理员**（admin）。超级管理员管理管理员账号并分配模块权限，管理员只能进入被分配的模块。

## 角色

| 角色 | 说明 |
| --- | --- |
| `superadmin` | 超级管理员，拥有全部后台模块权限，可创建、修改、取消管理员 |
| `admin` | 管理员，权限由超级管理员按模块分配 |
| `user` | 普通用户，不能进入后台 |

升级已有部署时，系统会把最早创建的管理员提升为超级管理员，并给其余管理员补齐全部模块权限，因此升级后现有管理员的可操作范围不会变小。

## 权限项

| 键 | 模块 | 分组 |
| --- | --- | --- |
| `users` | 用户管理（修改用户、批量导入） | 运营 |
| `announcements` | 公告管理 | 运营 |
| `problems` | 题目管理（含测试数据） | 内容 |
| `problem_banks` | 题库管理 | 内容 |
| `contests` | 比赛管理 | 内容 |
| `submissions` | 评测记录与重测 | 内容 |
| `judges` | 测评机管理 | 内容 |
| `settings` | 系统设置与密钥 | 系统 |
| `backups` | 数据备份（生成、下载、删除备份） | 系统 |
| `logs` | 日志查看 | 系统 |

后台概览（`/api/admin/v1/stats`）对所有管理员开放。用户列表的只读查询也开放给所有管理员，便于题目归属选择器展示候选用户；修改用户、批量导入仍需要 `users` 权限。

## 接口

| 方法 | 路径 | 权限 |
| --- | --- | --- |
| GET | `/api/admin/v1/admins` | 超级管理员 |
| POST | `/api/admin/v1/admins` | 超级管理员 |
| PUT | `/api/admin/v1/admins/:id` | 超级管理员 |
| DELETE | `/api/admin/v1/admins/:id` | 超级管理员 |

管理员账号字段：`id`、`username`、`nickname`、`role`、`status`、`permissions`、`created_at`、`last_login_at`。

- 创建：`username`（4–20 位字母、数字、下划线或短横线）、`password`（6–64 位）、`nickname`（可留空，默认与用户名相同）、`permissions`（权限键数组）。
- 修改：`permissions`、`nickname`、`password`、`status`（1 启用 / 2 禁用），未提交的字段保持不变。
- 取消管理员：账号降级为普通用户并清空权限，登录状态立即失效。

## 限制

- 超级管理员不能被修改或取消管理员身份。
- 管理员要调整角色，只能在「管理员管理」里由超级管理员操作；「用户管理」里的角色下拉只对超级管理员可用，且不能把账号设为超级管理员。
- 管理员不能修改自己的角色。
- 被取消 `users` 权限的管理员仍可在「用户管理」里看到列表，但保存与导入会被拒绝，提示「当前管理员未被分配该模块的权限」。
- 权限变更后，被修改的管理员需要重新加载页面才会看到菜单变化。

## 常见错误

| 提示 | 原因 |
| --- | --- |
| `需要超级管理员权限` | 当前账号不是超级管理员 |
| `当前管理员未被分配该模块的权限` | 该模块权限未被分配 |
| `仅超级管理员可以调整角色` | 在用户管理中修改角色 |
| `不能在用户管理中把账号设为超级管理员` | 超级管理员只能在管理员管理中创建 |
| `不能修改超级管理员` | 编辑目标是超级管理员 |
| `该账号不是管理员` | 编辑目标不是管理员 |
| `用户名已被占用` | 用户名重复 |
| `存在无效的权限项：…` | 提交了未知的权限键 |
