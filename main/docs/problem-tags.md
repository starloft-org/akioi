# 题目标签

标签（tag）是题目的知识点标记，用于列表展示与搜索。标签既存在于题目 JSON 字段里，也有一份独立的目录表，便于统一取名与复用。

## 数据结构

| 表 | 说明 |
| --- | --- |
| `tags` | 标签目录：`id`、`name`（唯一）、`created_at` |
| `problem_tags` | 题目与标签的关联：`problem_id`、`tag_id`，两个字段一起做主键，重复关联会被忽略 |
| `problems.tags` | 题目自身的标签 JSON 数组（如 `["动态规划","图论"]`），列表与详情直接读它 |

两道题都写「动态规划」时，`tags` 里只有一行「动态规划」，两道题各自在 `problem_tags` 里引用同一个 `tag_id`。

## 写入规则

- 新建或编辑题目（后台 `POST/PUT /api/admin/v1/problems`、用户端 `POST/PUT /api/v1/my/problems`）以及导入题目时，服务端会：
  1. 清洗标签：去掉首尾空白、合并连续空格、丢弃空串、按顺序去重、单个标签最多 24 个字符、每题最多 20 个。
  2. 按标签名在 `tags` 里「取已有的或新建」——已存在则直接复用，不会重复创建。
  3. 重建这道题在 `problem_tags` 里的关联。
- 导入题目时标签随题目在同一个事务里写入。

## 历史数据

服务启动时 `AutoMigrate` 之后会执行一次幂等的标签回填：扫描所有题目 `tags` 字段里的标签，补齐 `tags` 与 `problem_tags`（已存在的不动）。因此老库升级后标签表会自动带上目前所有题目的标签。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/v1/tags` | 返回所有已在用的标签，按名称升序：`{ "items": [{ "id": 1, "name": "动态规划" }], "total": 1 }`，无需登录 |

## 前端行为

- 后台「新建/编辑题目」与「我的题目」新建弹窗里的标签选择框会加载 `/api/v1/tags` 作为候选项；
- 输入一个新标签后按 Enter 即可创建（`allow-create` + `default-first-option`），保存时由服务端落库；
- 已有标签直接点选即可复用，不会出现同名重复标签；
- 「我的题目」弹窗在接口不可用时退回内置的常用标签列表，仍可手动输入新标签。
