# AKIOI 功能清单（待取舍）

用法：把你不要的行**直接删掉**，或告诉我编号（如「删 U6、U7、P12」）。「建议」列只是我的倾向，最终以你的删除结果为准。

## 已确定的决策

| 项 | 决策 |
|---|---|
| 赛制 | OI 赛制：按测试点累加得分，同一题取多次提交的最高分，赛后出最终成绩 |
| 判题沙箱 | Docker + cgroup 单机（禁网、只读根、tmpfs 工作目录、CPU/内存硬限制） |
| 提交语言 | C++ 与 C |
| 技术栈 | Go1.20+/Gin + Vue3/Vite + MySQL8.0 + Redis7.0 + Docker Compose |

## 建议的默认取舍（可直接采纳）
